1

Put the board in install mode

First time only.

  1. Hold D0
  2. Press RESET
  3. Release D0 (screen goes dark)
2

Install the makerDevice firmware

In the list, pick USB JTAG/serial debug unit → Connect → Install.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. USB flashing needs HTTPS (or localhost).
After “Installation complete”, press RESET once.

Not listed? Try a data cable and repeat step 1.

3

Connect it to WiFi

2.4 GHz WiFi only. iPhone hotspot: turn on Maximize Compatibility.

Enter WiFi in the same window. If it closes first, use your phone:

  1. Join makerDevice-XXXX
  2. Open 192.168.4.1
  3. Pick your WiFi → Save
4

No code needed. Watch the status.
